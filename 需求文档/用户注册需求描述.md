# 用户注册 需求描述

## 功能概述
用户通过填写用户名、密码、邮箱完成账号注册。注册成功后提示「注册成功」并跳转登录页。

## 字段规则

| 字段 | 规则 |
|------|------|
| 用户名 | 3-20 个字符，仅允许字母、数字、下划线；唯一；不区分大小写（统一转小写存储） |
| 密码 | 6-20 个字符（仅做长度限制，不做复杂度校验） |
| 再次输入密码 | 与「密码」字段值一致 |
| 邮箱 | 符合标准邮箱格式；唯一；仅做格式校验，不发送验证邮件 |

## 正常流程
1. 用户填写用户名、密码、再次输入密码、邮箱。
2. 点击「注册」提交。
3. 全部校验通过后创建账号。
4. 提示「注册成功」，跳转登录页。

## 异常场景

| 场景 | 提示文案 |
|------|----------|
| 用户名已存在 | 用户名已存在 |
| 邮箱已被注册 | 邮箱已被注册 |
| 两次输入密码不一致 | 密码不一致，请重新输入 |
| 用户名格式不正确 | 用户名需为 3-20 位字母、数字或下划线 |
| 密码长度不正确 | 密码长度需为 6-20 位 |
| 邮箱格式不正确 | 请输入正确的邮箱格式 |
| 字段为空 | 分别提示：用户名不能为空 / 密码不能为空 / 请再次输入密码 / 邮箱不能为空 |

## 页面跳转
- 点击页面中的「登录」→ 跳转登录页。

## 备注
- 用户名唯一性校验不区分大小写（`Alice` 与 `alice` 视为同一用户名）。
- 密码在服务端以加密形式存储（具体方案见开发文档）。
