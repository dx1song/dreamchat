# 主页面 需求描述

## 功能概述
用户登录成功后进入主页面。页面提供「星座分析」「周公解梦」两个核心功能入口，以及「历史记录」「退出登录」入口。

## 访问控制
- 需登录后才能访问。
- 未登录访问时，跳转登录页。

## 页面布局

### 主内容区（垂直居中，从上往下依次排列）
1. 提示文本：**星梦智能助手**
2. 按钮一：**星座分析**
3. 按钮二：**周公解梦**

### 右上角
- 「历史记录」入口
- 「退出登录」入口

## 页面元素与交互

| 元素 | 位置 | 交互 |
|------|------|------|
| 提示文本「星梦智能助手」 | 居中 | 无 |
| 按钮「星座分析」 | 居中 | 点击跳转星座分析页 |
| 按钮「周公解梦」 | 居中 | 点击跳转周公解梦页 |
| 入口「历史记录」 | 右上角 | 点击跳转历史记录页 |
| 入口「退出登录」 | 右上角 | 点击退出登录，清除登录状态，跳转登录页 |

## 异常场景

| 场景 | 处理 |
|------|------|
| 未登录访问主页面 | 跳转登录页 |

## 备注
- 退出登录后清除当前登录状态，跳转登录页（不做二次确认）。
