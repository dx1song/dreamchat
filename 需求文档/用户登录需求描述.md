# 用户登录 需求描述

## 功能概述
用户通过用户名和密码登录系统，登录成功后进入主页面。

## 字段规则

| 字段 | 规则 |
|------|------|
| 用户名 | 必填 |
| 密码 | 必填 |
| 记住我 | 可选，勾选后延长登录状态有效期 |

## 正常流程
1. 用户填写用户名、密码（可选勾选「记住我」）。
2. 点击「登录」提交。
3. 校验通过后登录成功，跳转主页面。

## 异常场景

| 场景 | 提示文案 |
|------|----------|
| 用户名为空 | 用户名不能为空 |
| 密码为空 | 密码不能为空 |
| 登录失败（用户名不存在或密码错误） | 用户名或密码错误（不区分具体原因） |

## 记住我
- 默认不勾选。
- 勾选「记住我」：登录状态保持较长时间（建议 7 天）。
- 不勾选：登录状态在浏览器关闭后失效。

## 页面跳转
- 点击页面中的「注册」→ 跳转注册页。

## 备注
- 登录失败不做次数限制（不做防暴力破解）。
- 登录失败统一提示「用户名或密码错误」，不暴露账号是否存在。
