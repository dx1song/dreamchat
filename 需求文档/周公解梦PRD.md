# 周公解梦功能 PRD

## 一、功能概述
用户登录后填写梦境信息，系统调用 AI 生成个性化的梦境解读报告（核心寓意、针对性解读、现实建议、整体评价），报告保存到数据库并关联当前用户。

## 二、功能列表
1. 解梦表单填写与校验
2. AI 梦境解读生成
3. 解读报告展示
4. 解读报告保存

## 三、详细描述

### 3.1 表单字段

| 字段 | 控件类型 | 规则 |
|------|---------|------|
| 梦境内容 | 文本输入 | 至少 10 字，长度 ≤ 500 字；必填 |
| 做梦时间 | 下拉单选 | 今晚 / 昨晚 / 近三天内 / 近一周内 / 更早；必填 |
| 性别 | 下拉选择 | 男 / 女；必填 |
| 年龄 | 下拉选择 | 18-25 / 26-35 / 36-45 / 46-55 / 55+；必填 |
| 职业 | 文本输入 | 长度 ≤ 50 字；必填 |
| 近期状态 | 文本输入 | 长度 ≤ 50 字；选填 |
| 解梦关注点 | 下拉多选 | 预设选项：事业 / 感情 / 健康；至少选择 1 项；必填 |

### 3.2 AI 报告输出
报告必含以下模块：
- 梦境核心寓意
- 针对性解读（根据用户选中的关注点，如事业 / 感情 / 健康）
- 现实生活建议（3-5 条）
- 整体评价（好梦 / 普通 / 需要注意）

输出风格：温暖、共情、智慧。

### 3.3 报告保存
- 报告完整内容保存到数据库，关联当前用户。
- 与「历史记录查看」功能衔接，可在历史记录中回看。

## 四、业务规则
1. 用户必须已登录。
2. 除近期状态外，其余字段均必填。
3. AI 分析结果保存到数据库，关联当前用户。
4. 响应时间 < 10 秒。
5. AI 调用超时或失败时，提示「生成失败，请稍后重试」，允许用户重试；失败结果不保存。

## 五、验收标准
1. 已登录用户可访问周公解梦页面；未登录访问时跳转登录页。
2. 必填字段为空或格式错误时给出明确提示。
3. 梦境内容少于 10 字时，提示错误并阻止提交。
4. AI 返回的报告包含全部要求模块（核心寓意、针对性解读、3-5 条建议、整体评价）。
5. 报告生成响应时间 < 10 秒。
6. 报告保存成功并关联当前用户，可在历史记录中查看。
7. 用户只能查看自己的报告，数据相互隔离。

## 六、非功能性需求
- **性能**：AI 解读响应时间 < 10 秒。
- **安全**：登录鉴权、用户数据隔离、敏感信息保护。
- **可用性**：表单提交后展示 loading 状态，AI 生成中给用户明确反馈；生成失败/超时给出明确提示并支持重试。
- **兼容性**：支持主流浏览器。
