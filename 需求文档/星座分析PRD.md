# 星座分析功能 PRD

## 一、功能概述
用户登录后填写个人信息，系统根据出生日期推算太阳星座，并调用 AI 生成个性化的星座分析报告（性格、运势、幸运色/幸运数字、建议），报告保存到数据库并关联当前用户。

## 二、功能列表
1. 星座分析表单填写与校验
2. 星座类型推算
3. AI 分析报告生成
4. 分析报告展示
5. 分析报告保存

## 三、详细描述

### 3.1 表单字段

| 字段 | 控件类型 | 规则 |
|------|---------|------|
| 出生日期 | 年月日下拉选择 | 年份范围 1970-2008；必填 |
| 性别 | 下拉选择 | 男 / 女；必填 |
| 情感状态 | 下拉选择 | 单身 / 恋爱 / 已婚 / 离异 / 丧偶 / 其他；必填 |
| 职业身份 | 文本输入 | 长度 ≤ 50 字；必填 |
| 测算关注点 | 下拉多选 | 预设选项：性格 / 事业 / 情感 / 财运 / 健康；至少选择 1 项；必填 |

### 3.2 星座类型推算
- 根据出生日期的「月 + 日」推算 12 星座之一。

星座日期对照表：

| 星座 | 日期范围 | 星座 | 日期范围 |
|------|----------|------|----------|
| 白羊座 | 3.21 - 4.19 | 天秤座 | 9.23 - 10.23 |
| 金牛座 | 4.20 - 5.20 | 天蝎座 | 10.24 - 11.22 |
| 双子座 | 5.21 - 6.21 | 射手座 | 11.23 - 12.21 |
| 巨蟹座 | 6.22 - 7.22 | 摩羯座 | 12.22 - 1.19 |
| 狮子座 | 7.23 - 8.22 | 水瓶座 | 1.20 - 2.18 |
| 处女座 | 8.23 - 9.22 | 双鱼座 | 2.19 - 3.20 |

### 3.3 AI 报告输出
报告必含以下模块：
- 星座类型
- 性格特点分析
- 近期运势（事业 / 感情 / 健康 / 财运）
- 幸运色 / 幸运数字
- 建议和提醒

输出风格：温暖、有趣、专业。

### 3.4 报告保存
- 报告完整内容保存到数据库，关联当前用户。
- 与「历史记录查看」功能衔接，可在历史记录中回看。

## 四、业务规则
1. 用户必须已登录。
2. 所有字段必填。
3. AI 分析结果保存到数据库，关联当前用户。
4. 响应时间 < 10 秒。
5. AI 调用超时或失败时，提示「生成失败，请稍后重试」，允许用户重试；失败结果不保存。

## 五、验收标准
1. 已登录用户可访问星座分析页面；未登录访问时跳转登录页。
2. 表单所有字段必填，空值或格式错误时给出明确提示。
3. 提交后正确推算星座类型，与出生日期匹配。
4. AI 返回的报告包含全部要求模块（星座类型、性格、运势、幸运色/数字、建议）。
5. 报告生成响应时间 < 10 秒。
6. 报告保存成功并关联当前用户，可在历史记录中查看。
7. 用户只能查看自己的报告，数据相互隔离。

## 六、非功能性需求
- **性能**：AI 分析响应时间 < 10 秒。
- **安全**：登录鉴权、用户数据隔离、敏感信息保护。
- **可用性**：表单提交后展示 loading 状态，AI 生成中给用户明确反馈；生成失败/超时给出明确提示并支持重试。
- **兼容性**：支持主流浏览器。
