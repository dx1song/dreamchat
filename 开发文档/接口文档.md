# 星梦智能助手 API 接口文档

## 一、基础信息

| 项目 | 说明 |
|------|------|
| 基础路径 | `/api` |
| 协议 | HTTP / HTTPS |
| 数据格式 | JSON（UTF-8） |
| 认证方式 | JWT Bearer Token（除注册/登录外均需登录） |

## 二、统一响应格式

所有接口返回统一结构：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 成功；非 0 失败 |
| message | string | 提示文案，可直接展示给用户 |
| data | object \| array \| null | 业务数据，失败时为 null |

## 三、错误码

| code | 含义 | HTTP 状态码 |
|------|------|-------------|
| 0 | 成功 | 200 |
| 40001 | 参数校验失败（字段为空 / 格式错误 / 重复等，`message` 为具体文案） | 400 |
| 40101 | 未登录或 token 无效 / 过期 | 401 |
| 40102 | 用户名或密码错误 | 401 |
| 40401 | 记录不存在 | 404 |
| 50001 | AI 生成失败 / 超时 | 500 |

## 四、认证说明

- 登录 / 注册成功后返回 JWT `token`。
- 后续请求在请求头携带：`Authorization: Bearer <token>`。
- 「记住我」勾选 → token 有效期 7 天；不勾选 → 24 小时。
- 所有接口均按当前登录用户的 `user_id` 过滤数据，**只能操作自己的数据**。

## 五、接口列表

### 1. 用户注册

`POST /api/auth/register`

**功能**：创建账号，成功后跳转登录页（不自动登录）。

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 3-20 位字母/数字/下划线，唯一，不区分大小写 |
| password | string | 是 | 6-20 位 |
| email | string | 是 | 标准邮箱格式，唯一 |

> 「再次输入密码」由前端校验，后端不接收。

```json
{
  "username": "alice",
  "password": "123456",
  "email": "alice@example.com"
}
```

**成功响应：**

```json
{
  "code": 0,
  "message": "注册成功",
  "data": { "id": 1, "username": "alice" }
}
```

**失败示例：**

```json
{ "code": 40001, "message": "用户名已存在", "data": null }
{ "code": 40001, "message": "邮箱已被注册", "data": null }
{ "code": 40001, "message": "用户名需为 3-20 位字母、数字或下划线", "data": null }
{ "code": 40001, "message": "密码长度需为 6-20 位", "data": null }
{ "code": 40001, "message": "请输入正确的邮箱格式", "data": null }
{ "code": 40001, "message": "用户名不能为空", "data": null }
```

### 2. 用户登录

`POST /api/auth/login`

**功能**：登录成功返回 token，跳转主页面。

**请求体：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |
| remember_me | boolean | 否 | 是否记住我，默认 false |

```json
{
  "username": "alice",
  "password": "123456",
  "remember_me": true
}
```

**成功响应：**

```json
{
  "code": 0,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "token_type": "Bearer",
    "user": { "id": 1, "username": "alice" }
  }
}
```

**失败示例：**

```json
{ "code": 40102, "message": "用户名或密码错误", "data": null }
{ "code": 40001, "message": "用户名不能为空", "data": null }
{ "code": 40001, "message": "密码不能为空", "data": null }
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| birth_date | string | 是 | 出生日期，`YYYY-MM-DD`，年份 1970-2008 |
| gender | string | 是 | 男 / 女 |
| relationship | string | 是 | 单身 / 恋爱 / 已婚 / 离异 / 丧偶 / 其他 |
| job | string | 是 | 职业身份，≤50 字 |
| focuses | array[string] | 是 | 测算关注点，至少 1 项（性格 / 事业 / 情感 / 财运 / 健康） |

```json
{
  "birth_date": "1995-04-05",
  "gender": "男",
  "relationship": "单身",
  "job": "软件工程师",
  "focuses": ["性格", "事业"]
}
```

**成功响应：**

**失败示例：**


**成功响应（type=dream）：**

## 六、无后端接口的功能说明

| 功能 | 实现方式 |
|------|----------|
| 退出登录 | 前端清除本地 token，跳转登录页，**无后端接口** |
| AI 失败重试 | 复用 `POST /api/astro/analyze` 或 `POST /api/dream/analyze`，失败后由前端再次调用 |
| 密码不一致校验 | 前端在注册页校验，后端不参与 |

## 七、数据隔离约定

所有需登录接口从 token 解析 `user_id`，查询/更新/删除时强制携带 `user_id` 条件，确保**用户只能操作自己的数据**；访问他人记录 id 时返回 `40401 记录不存在`（不泄露记录是否存在）。
