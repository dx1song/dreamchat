# 星梦智能助手 业务术语表

> 说明：本表统一项目内业务概念的定义，避免产品、开发、测试之间的理解偏差。术语定义以需求文档为准。

## 一、产品与角色

| 术语 | 定义 |
|------|------|
| 星梦智能助手 | 产品名称，一款提供「星座分析」「周公解梦」两大 AI 功能的应用。 |
| 访客 | 未登录用户（含已注册但未登录者），仅可使用注册、登录功能。 |
| 已登录用户 | 通过登录鉴权的用户，可使用星座分析、周公解梦、历史记录、退出登录等全部功能。 |
| 主页面 | 已登录用户登录后进入的首页，提供星座分析、周公解梦、历史记录、退出登录等入口。 |

## 二、账户与认证

| 术语 | 定义 |
|------|------|
| 注册 | 访客填写用户名、密码、邮箱创建账号的过程，成功后跳转登录页。 |
| 登录 | 访客通过用户名和密码完成身份验证，成功后进入主页面。 |
| 用户名 | 用户账号标识，3-20 位字母、数字或下划线，唯一，不区分大小写（统一转小写存储）。 |
| 密码 | 用户身份凭证，6-20 位字符，仅做长度校验，不做复杂度校验。 |
| 邮箱 | 用户注册时填写的联系方式，标准格式且唯一，仅做格式校验、不发送验证邮件。 |
| 记住我 | 登录页可选选项，勾选后登录状态保持 7 天，不勾选则浏览器关闭后失效；默认不勾选。 |
| 退出登录 | 已登录用户主动清除登录状态并跳转登录页的操作，不做二次确认。 |

## 三、星座分析

| 术语 | 定义 |
|------|------|
| 星座分析 | 根据出生日期推算太阳星座，并生成个性化星座报告的功能。 |
| 太阳星座 | 根据出生日期（月 + 日）推算出的 12 星座之一，如「白羊座」。 |
| 星座类型 | 12 星座的具体名称（白羊座～双鱼座），由出生日期推算得出，含摩羯座跨年边界处理。 |
| 出生日期 | 用户出生的年月日，年份范围 1970-2008。 |
| 性别 | 用户性别，取值：男 / 女。 |
| 情感状态 | 用户情感状态，取值：单身 / 恋爱 / 已婚 / 离异 / 丧偶 / 其他。 |
| 职业身份 | 用户从事的职业描述，长度 ≤ 50 字，必填。 |
| 测算关注点 | 用户选择的关注维度，取值：性格 / 事业 / 情感 / 财运 / 健康，下拉多选，至少 1 项；AI 据此侧重分析。 |
| 近期运势 | 报告模块，按事业 / 感情 / 健康 / 财运四个维度给出星级与解读。 |
| 幸运色 | 报告中的幸运颜色。 |
| 幸运数字 | 报告中的幸运数字。 |
| 建议和提醒 | 报告中的生活建议列表。 |

## 四、周公解梦

| 术语 | 定义 |
|------|------|
| 周公解梦 | 根据梦境描述生成个性化梦境解读报告的功能。 |
| 梦境内容 | 用户对梦境的文字描述，长度 10-500 字，必填。 |
| 做梦时间 | 梦境发生的时间段，取值：今晚 / 昨晚 / 近三天内 / 近一周内 / 更早。 |
| 年龄档 | 用户年龄区间，取值：18-25 / 26-35 / 36-45 / 46-55 / 55+。 |
| 性别 | 用户性别，取值：男 / 女。 |
| 职业 | 用户从事的职业描述，长度 ≤ 50 字，必填。 |
| 近期状态 | 用户当前身心状态的文字描述，长度 ≤ 50 字，选填。 |
| 解梦关注点 | 用户选择的关注维度，取值：事业 / 感情 / 健康，下拉多选，至少 1 项；AI 据此针对性解读。 |
| 梦境核心寓意 | 报告模块，对梦境整体含义的解读。 |
| 针对性解读 | 报告模块，按用户选中的关注点分别给出解读。 |
| 现实生活建议 | 报告模块，3-5 条生活建议。 |
| 整体评价 | 报告模块，三档评定：好梦 / 普通 / 需要注意。 |
| 梦境关键词 | 从梦境内容提炼的简短关键词（如「梦见蛇」），用于历史列表展示。 |

## 五、历史记录

| 术语 | 定义 |
|------|------|
| 历史记录 | 已登录用户产生的分析记录，含星座分析、周公解梦两类，保存完整结果，仅本人可见。 |
| 详情页 | 点击历史记录进入的页面，展示该次分析的完整内容（用户输入与分析全文），并提供删除入口。 |
| 删除单条 | 删除某一条历史记录的操作，删除前二次确认，删除后不可恢复。 |
| 清空全部 | 清空当前标签页该类全部记录的操作，清空前二次确认，不可恢复。 |
| 分页加载 | 历史记录按时间倒序、每页 20 条分页展示。 |

## 六、通用

| 术语 | 定义 |
|------|------|
| AI 分析 | 调用大模型（DeepSeek）生成分析报告的过程，响应时间 < 10 秒。 |
| AI 生成失败重试 | AI 调用失败或超时后，用户可重新提交生成的操作，提示「生成失败，请稍后重试」，失败结果不保存。 |
